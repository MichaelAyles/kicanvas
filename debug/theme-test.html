KiCanvas Theme Test

This page tests the theme attribute for the <kicanvas-embed> element.

Use the "Toggle Page Theme" button to switch between light and dark modes. The KiCanvas viewers will automatically update their themes to match.

Valid theme values are:

  • witchhazel - Dark theme (dark for both schematics and boards)
  • kicad - KiCAD default theme (light schematics, dark boards)

Note: The KiCAD default theme uses a light background for schematics but a dark background for boards, matching KiCAD's official color scheme.
